# まなびカード Ver.4.3

教員が問題集を作成・配布し、生徒がカードで学習する、一問一答アプリです。アカウント不要。アプリ本体は **index.html の1ファイル**で、外部ライブラリ・画像・APIに依存しません。

## 使い方

- パソコンでは `index.html` をブラウザーで開きます。ダウンロード済みのHTMLは通信なしで動作します。
- iPadでは、GitHub Pagesの公開URLをSafariで開く方法を推奨します。ローカルHTMLの実行可否は端末・学校の設定によります。
- 「学習する」で範囲と順番を選択します。カードのタップで答えを確認し、「できた」「もう一度」「保留」で自己判定します。
- 問題集の進捗率は、全問題のうち最後の判定が「できた」の問題が占める割合です。「もう一度」「保留」「未学習」は完了に含めません。
- 標準問題集として「酸アルカリとイオン」（55問）、「電池とイオン」（45問）、「力の合成・分解」（46問）を収録しています。
- 問題面は左右スワイプで移動、答え面は右＝できた・左＝もう一度・下＝保留。すべてボタンでも操作できます。
- 長い文章は文章部分を縦にスクロールできます。下スワイプ判定はカードの余白から行ってください。
- 結果は5秒後にホームへ戻ります。「結果を表示し続ける」で停止できます。

## 教員向け

「新規作成」から問題集を作り、問題・答え・ヒント・解説・難易度・タグを登録します。「一括登録」ではCSVファイルの読み込み、または1行1問の `問題｜答え｜ヒント｜解説` 形式での貼り付けができます。問題集情報の変更、問題の削除・上下移動、問題集の削除・自分用複製にも対応しています。

CSVは、先頭行に `問題,答え,ヒント,解説,難易度,タグ` の見出しを置きます。「問題」と「答え」は必須列で、ほかの列は省略できます。Excelでは「CSV UTF-8（コンマ区切り）」で保存してください。一般的なShift_JIS形式のCSVも読み込めます。アプリ内の「ひな形を保存」から、Excelで開けるサンプルCSVを取得できます。セル内のカンマ、改行、二重引用符にも対応しています。

問題集カードの「配布JSON」で、その問題集だけを書き出します。学習記録やチェックは含みません。生徒はアプリ内の「先生の問題を読み込む」でファイルを選び、確認して追加します。配布教材は編集できませんが、自分用に複製できます。

更新版は同じ元問題集から書き出してください。配布元ID・問題IDを維持すると、生徒側の更新時に既存の学習記録・チェックを引き継ぎます。内容を変更した問題も同じIDなら記録を引き継ぎます。別の問題として扱う場合は削除して新規登録してください。旧Ver.4.2が読み込み時に生成したIDからは、元の配布問題との対応を復元できません。

## 保存とバックアップ

データ管理（⚙）から全データのバックアップと復元ができます。復元は確認後に端末内の全データを置き換えます。配布JSONとバックアップは別形式です。旧形式のバックアップ（books・records・sessions・theme）も読み込めます。

保存は同じブラウザー・同じサイトのlocalStorageです。別のブラウザー・別のURLへの移行にはバックアップを使ってください。ブラウザーのデータ削除で記録は失われます。保存容量不足時には通知するので、バックアップを保存してください。破損した保存データがある場合は自動上書きを止めます。

学習データをアプリから外部へ送信する機能はありません。GitHub Pagesを開くときには通常のWebアクセスが発生します。公開URLをオフラインで再読込できることは保証しません（Service Workerは使用していません）。

## GitHubでの公開

1. GitHubで空のリポジトリを作成します。公開してよい教材だけを含めてください。
2. このフォルダのファイルをコミットして、リポジトリの `main` または `master` にpushします。
3. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定します。
4. **Actions → Publish GitHub Pages → Run workflow** を実行します。以降はpushで更新されます。
5. 完了後にPagesのURLを生徒へ案内します。

公開するのは `index.html` と `.nojekyll` だけです。自作教材・バックアップをリポジトリに含める必要はありません。

公開設定の参考：[GitHub公式のカスタムワークフロー手順](https://docs.github.com/ja/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。

## 開発と確認

Node.js 20以降で次を実行します。テスト用のPlaywrightは開発時のみ使用します。

```sh
npm install
npx playwright install chromium
npm test
```

テストはローカルHTTPサーバーを起動し、カード操作・保存・読み込み・更新・復元・結果画面・レスポンシブ表示を確認します。スクリーンショットは `test-results/` に保存します。

実機確認：公開前にiPad Safariでタップ・左右／下スワイプ・長文スクロール・ファイルの保存と読み込みを確認してください。自動テストはChromiumであり、iPad実機の動作を保証するものではありません。

今後の機能候補：チェック問題からの教材作成、出題数・タグ・難易度による絞り込み、学習時間・グラフ、PWA。現版では実装していません。
